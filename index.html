Problem StatementProcurement and Payment Status Tracking
MinistryMinistry of Agriculture & Farmers' Welfare
SchemePM-AASHA / MSP Price Support Scheme (PSS)
Tech StackVanilla JS (ES6+), CSS3, HTML5, PowerShell REST API, JSON DB
DatabaseJSON file (server) + LocalStorage (offline mode)
BackendPowerShell HttpListener REST API (run server.ps1)
Key Features Implemented:
✅ 8-Stage Procurement Timeline with Real-Time Tracking
✅ Farmer Dashboard with Stats & Charts
✅ Payment Tracking (DBT/PFMS Integration-ready)
✅ Admin Panel — Stage & Payment Update
✅ In-App Notifications (SMS/WhatsApp architecture ready)
✅ Full CRUD — New Procurement Registration
✅ Search & Filter — History & Payment Tables
✅ Role-Based Access (Farmer / Admin)
✅ Responsive Design (Mobile, Tablet, Desktop)
✅ Multi-Farmer Demo Support
✅ Offline Mode with LocalStorage fallback
